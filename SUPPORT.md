# Support

## Questions and bugs

Open an issue at <https://github.com/crisap94/herdr-plugins/issues/new/choose> and pick the template for your
plugin. The templates ask for the herdr version, your OS, the harness you use and the plugin's status output.

Before you report a bug, run the plugin's status action:

```bash
herdr plugin action invoke tab-recap.status
```

Replace your home folder with `~` in anything you paste, and do not paste transcripts or secrets.

## Security

Report vulnerabilities privately, as described in [SECURITY.md](SECURITY.md). Do not use a public issue.

## Problems in herdr itself

Problems in herdr core, rather than in a plugin, belong in herdr's own tracker:
<https://github.com/ogulcancelik/herdr/issues>.

## Plugin documentation

Each plugin has its own guide: start with [tab-recap/GUIDE.md](tab-recap/GUIDE.md).
