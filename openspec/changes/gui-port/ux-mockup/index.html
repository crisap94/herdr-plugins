Tab Recap, designed for a GUI

A mockup of the plan in ux-plan.md. Invented data, clickable. Nothing here is built yet.

1 · Ambient: always visible, zero clicks

Every agent pane gets a one-line strip: status shape, the headline (red when it needs you), and a context meter with the compaction threshold as a tick. The status bar chip is a fleet summary. Click it to open Fleet below.

Strip is an opt-in layout clone, never an edit of a shipped layoutShape plus colour for every statusTick = auto-compact hint

2 · Fleet and Brief

Fleet is a floating window ranking every tab of every space by urgency. Opening a row shows its Brief: lane chips (each one is the compact button), what changed since you last looked, then the answer to "what do you need from me".

Keys: j k, Enter, /, 1-4, c, r, Esc

3 · What changed from the terminal modal

  • Answer first. The need or headline leads everywhere; reasons and history are one click down.
  • Cross-tab by default. Fleet shows every tab, ranked, with how long each has waited.
  • Re-entry. "Since you last looked" is per viewer and per tab, computed from fact times.
  • Actions in context. The lane chip is the compact button; a blocked need has Jump and Reply beside it.
  • Nothing lost. Every terminal element has a home (see the parity table in ux-plan.md).
