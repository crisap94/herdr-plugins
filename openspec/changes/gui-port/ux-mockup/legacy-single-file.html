2 · The recap window

A persistent, draggable window. Pick a view: Fleet ranks every tab of every space by urgency; Brief is the re-entry card; Timeline is drawn, not listed; Compact shows the action in context.

3 · What changed from the terminal modal

  • Answer first. The need or headline is the first line everywhere; reasons and history are one click down.
  • Cross-tab by default. The terminal showed one tab; Fleet shows all, ranked, with how long each has waited.
  • Re-entry. "Since you left" is computed per viewer from fact times, so coming back is a 5-second read.
  • Actions in context. The context meter is the compact button; a blocked need has Jump and Reply beside it.
  • Nothing lost. Every terminal element has a home (see the parity table in ux-plan.md).
