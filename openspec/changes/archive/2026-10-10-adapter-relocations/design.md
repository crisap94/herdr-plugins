# Design

The job registry declares typed environment names. `scrubbedEnv()` keeps its no-argument signature and scrubs the union of those names plus the existing `HERDR_` and `TAB_RECAP_` prefixes. The adapter owns Claude's two explicit names, while all callers keep the current environment output. A later telemetry tag can attach to each child environment after `scrubbedEnv()` returns: the optional default-off `JobTag` travels through `Make` in `daemon/harness-makers.ts`; Claude and Codex add the serialized attribute to the copied environment, while OpenCode, Hermes, and custom accept and ignore it. Git children remain untagged.

The screen adapter owns the existing chrome regexes and passes them to the application cleaner. The cleaner keeps the same removal order, line deduplication, and output for every screen reader kind.

The session adapter registry is keyed by `RegisteredKind`, with one shared identity function in each table entry and as the unregistered-kind fallback. Agent-provided values are parsed through compatibility constructors so whitespace-only ids and empty basenames remain valid results; a basename that becomes the empty string stops candidate lookup as it did before. Codex, OpenCode, and unknown kinds retain today's basename and `.jsonl` stripping behavior on purpose; deciding whether their path interpretation should differ is a later change. `decode.ts` reads the lane's `agent` field and passes it to the registry. Decoder entry points require an explicit identity function and remain total for degenerate agent values.

Observed context parsers move to adjacent per-harness modules, with JSONL row parsing and positive finite count parsing in one shared context-values module. Tool-name maps move to per-harness modules, while the shared call builders, shell classification, clipping and entry construction remain in `tool-calls.ts`. Each map classifies only its own native vocabulary; a foreign name is `other`, even when another adapter recognizes it. Per-adapter goldens pin every native name and one foreign name. The regexes, maps, and environment prefix filter are hand-written because Node has no built-in for interpreting these harness transcript formats, removing their terminal chrome, classifying tool names, or selecting environment variables by prefix and registered name. The session helper parses both slash styles independent of the host OS because `node:path` basename follows the host platform and would not preserve Windows path behavior on every host.
